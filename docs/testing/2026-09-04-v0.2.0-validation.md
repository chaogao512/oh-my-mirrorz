- 生成一项 `~/.condarc` 计划；
- 对 `osx-arm64/repodata.json` 完成写入前预检；
- 显示 MirrorZ 本次实际路由目标；
- 未写入配置，未创建切换事务。

## 真实镜像烟雾测试

对每个候选执行一次只读低成本探测，以下能力均至少有一个成功候选：

- PyPI simple；
- npm registry；
- Cargo sparse index；
- Homebrew API、bottles、build-time PyPI；
- Ubuntu main、ports mirrorlist/endpoint；
- Conda defaults `osx-arm64`；
- Conda-forge `osx-arm64`（隔离临时配置）。

MirrorZ 的动态目标在报告中显示为最终域名；APT 没有被标记为单一最快站点；npm 的 `auto` 与 `npmmirror` 相同 URL 只发起一次探测并复用结果。

## 结论

v0.2.0 满足已确认的统一管理原则：相同策略、相同事务、相同 benchmark 输出，由各适配器仅提供配置语义和协议探测差异。发布前检查通过。
